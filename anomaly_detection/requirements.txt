# ============================================================================
# requirements.txt — Python dependencies for this project

# We keep the list minimal: only what is truly needed.
#
#   paho-mqtt      → MQTT client for subscribing to sensor data and publishing alerts
#   numpy          → numerical arrays, used everywhere for data manipulation
#   scikit-learn   → provides MinMaxScaler for normalising sensor values to [0,1]

# per environment:
#
#   PC image (Dockerfile, amd64, CPU):  tflite-runtime 2.14  (inference only, a few MB)
#   NPU image (Dockerfile.npu, arm64):   ai-edge-litert, plus the device's own
#                                        tflite_runtime, lent read-only at run time
#
#   Training (local, outside Docker):  tensorflow
#     pip install -r requirements.txt tensorflow
# ============================================================================
